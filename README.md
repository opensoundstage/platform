# OpenSoundstage

**Music without gatekeepers.**

OpenSoundstage is a free, open-source, API-first music platform empowering independent artists, record labels, and communities through collaboration, discovery, and creative freedom.

## Deploy to Netlify

1. Add these files to the `opensoundstage/platform` GitHub repository at the repository root.
2. In Netlify, choose **Add new project → Import an existing project → GitHub**.
3. Select the `opensoundstage` organization and `platform` repository.
4. Set production branch to `main`, leave the build command empty, and set publish directory to `.`.
5. Deploy. Connect `opensoundstage.com` under **Domain management** after the site works.

No framework, package installation, database, or build command is required.

## Contents

- `index.html` — homepage content
- `styles.css` — responsive styles
- `script.js` — dynamic copyright year
- `assets/opensoundstage-logo.png` — approved logo image
- `netlify.toml` — deploy settings and basic security headers
