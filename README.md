# OpenSoundstage homepage — BUILD concept update

A static, responsive concept homepage for OpenSoundstage. Explains the four BUILD primitives (GET, PUT, LINK, DO), the sandbox/grain metaphor, and a simple song-to-show example. Includes a lightweight interactive demonstration; **no backend, uploads, audio playback, or BUILD runtime** is implemented.

## Deploy

Copy the **contents** of this folder into the root of `opensoundstage/platform` on `main`. Netlify is already connected to the repository. This is a static site; no build command is needed. Keep the included `assets/opensoundstage-logo.png`, `netlify.toml`, `styles.css`, and `script.js` together with `index.html`.

The existing custom domain and DNS do not need to change. No license has been chosen yet; decide on an open-source license before inviting code reuse.
